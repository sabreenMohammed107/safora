# اللغتان: العربية والإنجليزية (متطلب أساسي)

> كل شاشة وكل بيان يظهر للمستخدم يكون **بالعربية والإنجليزية** من أول سبرنت — مش إضافة في الآخر.

## 1) الواجهة (Interface)
| البند | القرار |
|---|---|
| مبدّل اللغة | زر AR / EN في الأدمن والبوابة · يُحفظ في `users.locale` / `client_users.locale` |
| الاتجاه | `dir="rtl"` للعربي و `dir="ltr"` للإنجليزي على `<html>` |
| CSS | استخدام الخصائص المنطقية فقط: `ms-* me-* ps-* pe-* start end` (النموذج الأولي يستخدمها فعلاً) — ممنوع `ml/mr/left/right` |
| الخطوط | Cairo للعربي · Inter / Montserrat للإنجليزي |
| النصوص الثابتة | ملفات `lang/ar/*.php` و `lang/en/*.php` (أو JSON) — **لا نص عربي داخل Blade مباشرة** |
| الأرقام والتواريخ والعملة | `Carbon::setLocale()` · أرقام لاتينية في الاثنين · «ر.س» / «SAR» |
| الأيقونات الاتجاهية | الأسهم (رجوع/التالي) تنعكس حسب الاتجاه |
| رسائل التحقق | `lang/*/validation.php` |

## 2) البيانات (Content)
**كل حقل نصي يراه المستخدم = عمود لكل لغة** (`*_ar` / `*_en`) أو عمود JSON مع `spatie/laravel-translatable`.
> القرار المقترح: **spatie/laravel-translatable** (عمود JSON واحد `{"ar":"…","en":"…"}`) لأنه أسهل مع أعمدة النماذج المتغيرة.

| الكيان | الحقول المترجمة |
|---|---|
| الخطط | name, modules labels |
| القطاعات / المنتجات | name (المنتجات فيها `ar` و `en` بالفعل) |
| برامج PRPs | name, summary, record_name, acceptance, limit_text, steps, evidence, failure, haccp_link, responsible, frequency |
| مجموعات PRPs | label |
| النماذج (`haccp_forms` / `iso_forms`) | title, freq, config.purpose, config.acceptance, config.note, **كل column.label و column.options** |
| قوالب خطط الهاسب | كل نصوص الأقسام الـ13 |
| CCP / الحدود / التتبع | الأسماء والأوصاف والحدود |
| إجراءات ISO | title وكل المحتوى |

**شكل عمود النموذج بلغتين:**
```json
{ "id":"result", "type":"select", "required":true,
  "label":{"ar":"النتيجة","en":"Result"},
  "options":[ {"value":"pass","ar":"مطابق","en":"Compliant"},
              {"value":"fail","ar":"غير مطابق","en":"Non-compliant"},
              {"value":"na","ar":"لا ينطبق","en":"N/A"},
              {"value":"pending","ar":"قيد التحقق","en":"Under verification"} ] }
```
> ⚠️ **مهم:** السجلات تحفظ **القيمة** (`pass` / `fail`) وليس النص — عشان التقارير والعدادات تشتغل في اللغتين.
> النموذج الأولي يحفظ النص العربي («غير مطابق»)؛ أداة الاستيراد تحوّله لقيمة.

## 3) ما يكتبه العميل (Records)
- بيانات السجلات نفسها (ملاحظات، أسماء…) تُحفظ **كما كتبها المستخدم** بدون ترجمة.
- عناوين الأعمدة والخيارات والرأس تظهر بلغة الواجهة.

## 4) الطباعة / PDF
- الطباعة بلغة المستخدم الحالية (أو اختيار لغة الطباعة).
- `mpdf` يدعم العربية والاتجاهين · نفس قالب EIB بالاتجاهين.

## 5) الترجمة المطلوبة للبيانات الحالية
| البيانات | العدد | الحالة الحالية |
|---|---|---|
| برامج PRPs | 22 | عربي فقط |
| نماذج EIB | 176 نموذج (~1,400 عنوان عمود) | عربي فقط |
| نماذج ISO | 23 | جزء منها فيه عنوان إنجليزي |
| إجراءات ISO | 28 | عربي |
| قوالب خطط الهاسب | 13 قسم × عدة منتجات | عربي |
| المنتجات | المكتبة | ✅ عربي + إنجليزي |
| النصوص الثابتة للواجهة | ~600–900 نص | عربي |

> الترجمة الفنية تحتاج **مراجعة متخصص سلامة غذاء** (مصطلحات HACCP / ISO 22000 الرسمية).
