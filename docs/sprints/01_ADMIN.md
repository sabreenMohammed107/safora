## A. مركز قيادة الهاسب `0_HACCPCenter.html`
**المؤشرات:** عدد البرامج · النماذج (نشط/مسودة) · عملاء خطتهم تشمل الهاسب · سجلات العملاء.

**البرامج (22 PRP من مكتبة V17)**
- شريط البرامج PRP-01 … PRP-22 + بحث.
- بطاقة البرنامج: الاسم، المجموعة، الحالة، الوصف، المسؤول، التكرار، إحصائيات.
- **محتوى الإجراء مفتوح دائماً** (حقول قابلة للكتابة + زر حفظ ثابت + «تراجع» + تنبيه عند الخروج بدون حفظ):
  الاسم، المجموعة، الحالة، الوصف، المسؤول، التكرار، اسم السجل، معيار القبول، الضوابط، الخطوات، الأدلة، التصرف عند عدم المطابقة، صلة HACCP.
- برنامج جديد (مع خيار إنشاء نموذجين قياسيين) · حذف البرنامج المضاف يدوياً فقط.
- 7 مجموعات: البنية التحتية · النظافة والآفات · العاملون · المعدات · سلسلة الإمداد · منع التلوث · التتبع والحماية.

**جدول نماذج البرنامج:** الرمز (+ كود EIB) · الاسم · التكرار · البنية (نوع التخطيط + عدد الأعمدة) · الحالة (نشط/مسودة بضغطة) · السجلات · تعديل · نسخ · حذف.
- «تعديل» / «نموذج جديد» يفتحان الاستوديو ويرجعان لنفس البرنامج بعد الحفظ أو الإلغاء.
- **لا يوجد إسناد يدوي**: كل نموذج «نشط» يظهر لكل عميل خطته تشمل الهاسب.

**نماذج PRPs = 176 نموذج EIB** (22 × 8) من ملفات `03…06_EIB_PRP_Forms`:
`تاريخ التنفيذ` + 8 أعمدة تخصصية + `مرجع الدليل` + `النتيجة` (مطابق/غير مطابق/لا ينطبق/قيد التحقق) + `رقم CAPA` · 30 صف للطباعة · معيار القبول · ملاحظة التذييل.
الكود: `P01-F01` في Excel = `PRP-01-F01` في النظام.

## B. استوديو النماذج `2_FormBuilder.html`
- مفتاح المعيار: **الهاسب | ISO 22000** — كل معيار له جدوله.
- اختيار الإجراء/البرنامج · الكود يتولد تلقائياً (`PRP-05-F09` / `P-03-F02`) ولا يتغير بعد الإنشاء.
- مكتبة + فلتر بالنوع + بحث · تعديل · نسخ · حذف · معاينة وطباعة.
- **10 أنواع تخطيط**:

| النوع | الاستخدام |
|---|---|
| `eib_log` سجل تشغيلي EIB | كل نماذج PRPs (ترويسة + غرض + معيار قبول + جدول + تذييل اعتماد) |
| `simple` حقول بسيطة | تقرير زيارة (نص، رقم، تاريخ، وقت، اختيار، توقيع، صورة…) |
| `dated_grid` سجل بتواريخ | سجلات يومية/شهرية بأعمدة |
| `matrix_month` مصفوفة شهرية | فئات × 31 يوم |
| `audit_sections` تفتيش بأقسام | بنود مطابق/غير مطابق/لا ينطبق |
| `report_entry` بلاغ/إدخال متكرر | حقول متعددة الأنواع + إجباري |
| `reference_table` جدول مرجعي | صفوف ثابتة تُعبأ مسبقاً للعميل |
| `tag_card` بطاقة ميدانية | كارت المصيدة |
| `site_map` خريطة مواقع | صورة المخطط + دليل رموز + اعتماد |
| `trend_report` تقرير اتجاهات | مناطق × أنواع + رسم بياني تلقائي عند العميل |

- كل نوع يتحول عند العميل لأعمدة سجل بدالة واحدة `layoutToFields()` (نفس المحرك للمعيارين).

## E. مركز العملاء `11_ClientCenter.html` (أدمن)
**التبويبات:** إدارة العملاء · طلبات العملاء · تصنيفات القطاعات · الخطط والأسعار.

**جدول العملاء:** الاسم، التصنيف، الخطة (+ عدد الفروع + الإجمالي)، الحالة، الانتهاء، إجراءات (مراجعة/دخول كعميل/إدارة).

**ملف العميل (درج جانبي):**
- بيانات المنشأة والسجل التجاري · ربط الوحدات (أعداد) · القطاعات المسموحة (+ منح قطاع).
- **محتوى الخطة**: ملخص الهاسب و ISO (مفتوح/مقفول + الأعداد) — بدل الإسناد اليدوي.
- **الفروع**: إضافة/تعديل/إيقاف · عدد المنتجات والسجلات والمستخدمين لكل فرع · ملاحظة تكلفة الفرع الإضافي.
- **المستخدمون**: إضافة/تعديل/إيقاف · الدور والفرع · توليد كلمة مرور + رسالة جاهزة للنسخ.
- المستندات · الاشتراك (الخطة، الدورة، الخصم، التواريخ، بريد الدخول) مع تفصيل السعر · سجل النشاط.
- «دخول كعميل» (محاكاة البوابة كمدير الشركة).

**الخطط والأسعار:** خطتان فقط (لا إضافة/حذف) — تعديل السعر والوحدات والفروع المشمولة وسعر الفرع الإضافي وحد الفروع.

**الطلبات:** طلبات تسجيل · طلبات منتجات (عند القبول يُضاف المنتج **للفرع الذي طلبه**).
