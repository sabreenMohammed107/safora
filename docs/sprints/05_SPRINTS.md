# خطة السبرنتات (Laravel + MySQL)

> سبرنت = **أسبوعين**. الترتيب: **الأساس ← أدمن الهاسب ← بوابة الهاسب ← إطلاق الهاسب ← ISO**.
> كل سبرنت ينتهي بشيء يعمل ويُختبر. المرجع في كل مهمة: صفحة النموذج الأولي المذكورة.

**Definition of Done لكل سبرنت:** Migrations + Seeders · Policies للصلاحيات · Feature tests للمسارات الأساسية · واجهة مطابقة للنموذج · مراجعة على بيانات التجربة.
🌐 **+ اللغتان:** كل نص من ملفات اللغة · الشاشة تعمل RTL و LTR · البيانات الجديدة تُدخل بالعربي والإنجليزي · الطباعة باللغتين (قائمة `06_I18N.md` §6).
