# بوابة العميل (`11_ClientCenter.html#portal`)

> 🌐 البوابة بالعربي والإنجليزي: كل مستخدم يختار لغته، والاتجاه والطباعة يتبعان اللغة. ما يكتبه العميل في السجلات يُحفظ كما هو.

## الدخول والجلسة
- دخول بحساب **مستخدم** (بريد + كلمة مرور) — الشركة لها أكثر من مستخدم.
- «تذكرني» (localStorage) أو جلسة مؤقتة (sessionStorage).
- حجب البوابة إذا: الحساب موقوف · لا فرع مفعّل · لا خطة · الاشتراك منتهٍ/غير معتمد.

## الشريط الجانبي
- اسم الشركة + **اختيار الفرع** (مدير الشركة: «كل الفروع» + كل فرع · غيره: فرعه فقط) + اسم المستخدم ودوره.
- القائمة:
  - الرئيسية · المنتجات
  - **حزمة الهاسب**: برامج PRPs · خطط الهاسب · نقاط التحكم · الحدود الحرجة · التتبع والاستدعاء
  - **حزمة الأيزو**: الإجراءات والنماذج · 8 بنود ISO (بيانات تجريبية حالياً)
  - طلبات المنتجات · حسابي
- البنود خارج الخطة تظهر بقفل.

## وضع «كل الفروع» (مدير الشركة)
- عرض ومقارنة فقط. أي فتح نموذج/خطة يطلب اختيار الفرع.
- الرئيسية: جدول **مقارنة الفروع** (سجلات اليوم، 7 أيام، الإجمالي، عدم مطابقة مفتوحة، آخر سجل).

## المنتجات (لكل فرع)
- قطاعات مسموحة → اختيار المنتجات **للفرع الحالي** · «كل الفروع» = اتحاد للعرض فقط.
- طلب منتج غير مدرج (يُسجل باسم الفرع).

## برامج PRPs
- 22 برنامج في 7 مجموعات + عدادات (نسخة المنشأة، مراجعة داخلياً، برامج لها سجلات، مفتوحة).
- **البحث**: اسم/رمز البرنامج (`PRP-02 المباني والمرافق`) أو اسم/رمز النموذج (`PRP-02-F01 فحص سلامة المباني`، أو كود EIB `P13-F05`) → قائمة «نماذج مطابقة» مع «فتح».
- صفحة البرنامج: المحتوى (معيار القبول، الضوابط، الخطوات، الأدلة، عدم المطابقة، صلة HACCP) + بيانات الاعتماد + سجل المراجعات.
- **تخصيص لمنشأتي** (مدير الشركة فقط) + استعادة القالب · لا يُسجل «مراجع داخلياً» بدون مرجع ودليل ومراجِع ومعتمِد.
- نماذج البرنامج: كل النماذج النشطة (8 لكل برنامج).

## مساحة عمل النموذج (لكل نموذج)
- تبويبات نماذج نفس البرنامج · وصف/معيار القبول.
- **رأس النموذج** (لكل فرع ولكل نموذج، حفظ تلقائي): المنشأة، الفرع، البرنامج، مسؤول السجل، الإصدار، الفترة، موعد المراجعة، حالة الاعتماد، أُعد/روجع/اعتُمد، تاريخ الاعتماد.
- جدول بنمط Excel: إضافة في سطر · إضافة بنموذج · تعديل · حذف (مسؤول الفرع/المدير فقط) · نسخ آخر سجل · تثبيت قيم.
- فلاتر: الكل · اليوم · ناقصة · عدم مطابقة + بحث.
- **طباعة** (A4 عرضي): نفس شكل نموذج EIB بالرأس والسجلات وصفوف فارغة حتى 30 والتذييل.
- `trend_report`: رسم اتجاه تلقائي من السجلات.

## خطط الهاسب / نقاط التحكم / الحدود / التتبع (لكل فرع)
- الربط «ربط بالفرع» حسب منتجات الفرع.
- خطة الهاسب المربوطة تفتح **13 قسم معبأة من القالب** مرة واحدة لكل فرع، والعميل يعدّل.
- نقاط التحكم: مراقبة + انحراف · الحدود: قراءات · التتبع: تبويبات التتبع.

## حزمة الأيزو
- الإجراءات P-01…P-28 + نماذجها (خطة ISO فقط).
- 8 بنود ISO (السياسة، الوثائق، التدريب، الموردون، التدقيق، مراجعة الإدارة، عدم المطابقة، الطوارئ) — **بيانات تجريبية** تحتاج بناء فعلي.

## حسابي
- بيانات المستخدم · **الفروع** (المدير يضيف/يعدل/يوقف مع إظهار التكلفة) · **المستخدمون** (المدير) · الاشتراك وحدوده.
